FPGA vs. ESP32/PCA9685 Hardware Distinction
• FPGA Path (Direct RTL Synthesis):
  - Synthesizes rtl/*.v directly into FPGA LUTs & flip-flops
  - Override CLK_HZ = 50_000_000 (FRAME_TICKS = 1,000,000, TICKS_PER_US = 50)
  - 8 true parallel hardware PWM counters + 1-clock (20 ns) E-STOP
  - Requires external 5–6V high-current BEC, level shifters, servo calibration & IMU

• ESP32 + PCA9685 Path (Separate MCU Architecture):
  - ESP32 does NOT execute Verilog RTL directly
  - FSM & safety logic must be ported to C/C++ firmware
  - PCA9685 generates 50 Hz PWM over I2C

• Current Simulation Limitations:
  - Open-loop flat-ground gaits (no physical MPU6050 / foot force sensors)
  - Pulse-to-angle mapping requires physical servo endpoint calibration
